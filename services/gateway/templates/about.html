Tentang Aplikasi

Informasi sistem dan arsitektur platform SmartWafer.

SmartWafer adalah aplikasi web terintegrasi untuk mendukung klasifikasi defect dan clustering kondisi wafer berdasarkan data sensor secara real-time dan efisien.

⚙️

Fitur Utama

  • Klasifikasi defect wafer otomatis.
  • Clustering kondisi wafer berbasis sensor.
  • Gateway terpusat untuk komunikasi dengan service Machine Learning.
🏗️

Arsitektur Aplikasi

Frontend menyediakan antarmuka pengguna yang responsif, sedangkan Gateway menangani routing API serta komunikasi antara pengguna dan Microservice Machine Learning.
